# Report visualization

The offline inference report uses the existing Segoe UI / Microsoft YaHei typography, pale background, and restrained tables. Preserve its full input/output data and offline operation.

Peak comparisons use vertically aligned SVG plots for Python, Cython, and C, separately for batch and single calls. All plots for a case share the same retention-time and intensity scales. Peak boxes span the returned a/b interval; c is a numeric annotation, not an intensity. Use teal, amber, and purple alongside explicit implementation labels. Show empty results explicitly. Full precision remains available in tables, JSON, and SVG tooltips.
