# MRMPFormer 宽峰与复杂峰诊断

诊断日期：2026-09-09。评测使用当前 `test1.xlsx`、`test2.xlsx` 标签，预测起止边界均在容差内才计为 TP。

## 结论

当前 `mrmpformer.pth` 对宽峰和复杂峰的下降由三类因素叠加造成：训练宽度分布偏窄、FDR 修正范围受初始框宽限制、ResNet 最后一层特征分辨率不足。多峰还受到 3 个 query 无冗余、标签拆分口径和事件合并规则的影响。

现有 `mrmpformer_special_v2.pth` 已修复前两项中的损失与 FDR 尺度问题。使用阈值 0.8 时：

| 模型 | test1 P/R/F1 | test1 TP/FP/FN | test2 P/R/F1 | test2 TP/FP/FN |
|---|---|---|---|---|
| 当前 MRMPFormer，阈值 0.9 | 1.0000 / 0.9756 / 0.9877 | 80/0/2 | 0.9697 / 0.7191 / 0.8258 | 128/4/50 |
| special_v2，阈值 0.8 | 1.0000 / 0.9756 / 0.9877 | 80/0/2 | 0.9623 / 0.8596 / 0.9080 | 153/6/25 |

## 数据证据

test2 按人工峰宽分层，当前模型阈值 0.9、容差 0.1 min：

| 人工峰宽 | GT 数 | 当前召回 | special_v2 召回 |
|---|---:|---:|---:|
| <=0.25 min | 70 | 85.7% | 85.7% |
| 0.25–0.50 min | 75 | 86.7% | 94.7% |
| >0.50 min | 33 | 9.1% | 30.3% |

`traindatav1` 训练集共有 17,654 个框，归一化宽度中位数 0.1068；宽度大于 0.25 的框只有 6.16%，大于 0.4 的只有 1.61%。当前权重却在 test2 遇到 33/178（18.5%）个宽度超过 0.5 min 的峰，存在明显尺度分布差异。

宽峰常被预测为多个低分子框。啶虫脒-1 的三个候选分数约为 0.889、0.552、0.447，阈值 0.9 会全部删除。当前模型将阈值降至 0.5、容差放宽至 0.5 min 后召回从 71.9% 升至 94.9%，说明多数信号已经被模型看到，但置信度与边界表达不正确。

多峰的严格召回更低：test2 单峰为 78.9%，双峰为 12.5%，三峰为 0%。`special_v2` 对宽峰有效，但双峰/三峰严格召回仍只有 12.5%/0%，说明复杂峰需要更高分辨率和专门的事件级训练，不能只调阈值。

## 代码层原因

1. 当前动态 L1 的中心权重是 `1 / w_gt`，PW-CIoU 的中心项也是 `mean_width / w_gt`。两项都更强调窄峰；宽峰的中心和相对宽度误差受到的约束更弱。
2. 当前 FDR 使用 `initial_box_width` 作为偏移尺度。左右边界各最多移动约一个初始框宽，最终宽度受约 `3 × 初始框宽` 限制。初始框锁定子峰时，后续层难以扩成完整宽峰。
3. 模型只把 ResNet50 `layer4` 特征送入 Transformer。400 px 对应约 2 min，stride 32 后水平方向只有约 13 个特征位置，每个位置约 0.16 min。它接近 0.1 min 的评测容差，并会抹掉 0.04–0.10 min 的肩峰、谷底和窄子峰。
4. 每图只有 3 个 query，刚好等于标签允许的最大峰数。复杂峰一旦产生重复框或子峰框便没有冗余 query。
5. 训练与推理只做 `ToTensor + Normalize`，没有尺度、宽度、基线、拖尾和肩峰增强。图像输入还会丢失原始一维序列中的精细采样信息。
6. 训练标签、测试标签和 `peak_event_merge` 对“一个宽事件”还是“多个子峰”的判定需要统一，否则同一波形可能受到互相冲突的监督与后处理。

## 建议实施顺序

1. 先将候选模型切换为 `mrmpformer_special_v2.pth`，默认阈值改为 0.8，并完整重跑 test1/test2、特殊峰和空白样品。
2. 以 `special_v2` 为起点，用 `traindatav1 + traindatav2` 混合微调；按峰宽和峰数分层采样，并校准分类分数。不要直接部署仅在模拟宽峰上训练的 `mrmpformer_trainv2.pth`：它需要把阈值降到约 0.1 才在 test2 达到 F1=0.9191，分数分布与当前阈值明显不匹配。
3. 将 query 从 3 增加到 6，加入重复框抑制，并建立单峰/双峰/三峰分层指标。
4. 把主干输出提升到 stride 16，或融合 layer2/layer3/layer4 多尺度特征。更稳妥的长期方案是增加原始一维 XIC 分支，用一维特征负责谷底、肩峰和足点定位，图像分支负责整体形态。
5. 明确复杂峰标注规范，并让事件合并损失或后处理使用相同的谷深、肩峰和足点定义。

第 1 步已经用现有 ROI 完成可复核推理；输出保存在本目录的 `special_v2/` 和 `special_v2_test1/`。
