# 候选峰“最大峰强度 1/4”过滤规则审计

## 结论

`候选峰强度 < 同通道最大候选峰强度 × 0.25` 作为无条件硬过滤不合理，当前不应直接写入生产推理路径。

它能明显减少低强度额外峰和模型计算量，但现有数据已经证明：低于主峰 1/4 的候选中包含人工标签真峰、与传统算法正式匹配的峰，以及 `score_ai > 0.8` 的模型峰。强度相对较低只能作为弱证据，不能单独证明候选是假峰。

## 当前已有的候选强度门槛

当前 SciPy Phase-1 候选枚举已经同时使用两个全通道相对门槛：

1. 峰顶强度至少为 `baseline + 0.04 × dynamic`；
2. prominence 至少为 `0.055 × dynamic`；
3. 超过每通道 50 个候选时，代码按峰顶强度保留前 50 个。

其中 `dynamic = 通道最大平滑强度 - baseline`。所以 25% 规则不是增加第一层相对过滤，而是将峰高约束从 4% 大幅提高至 25%。

## test3_3 至 test3_58 精确反事实结果

审计使用当前 Phase-1 参数，从 56 个 mzML 重新枚举候选，并用每个通道的真实 Phase-1 最大候选峰作为分母。历史最终峰来自 `massnova_test3/all.csv`。

## 推荐设计

### 分数定义

相对峰强建议使用基线校正后的峰高：

`relative_height = (I_apex - baseline) / (I_max_candidate - baseline)`

并截断到 `[0, 1]`。直接用原始强度比会在高基线或基线漂移通道中夸大弱峰。

### 决策顺序

建议采用以下顺序：

1. 保留当前 4% 峰高、5.5% prominence 的候选枚举；
2. 为每个候选计算 `relative_height`，但先让全部候选经过 MRMPFormer；
3. `score_ai >= 模型阈值` 的模型峰不受 25% 规则删除；
4. 25% 仅作为模型未命中候选进入信号兜底路径的附加证据；
5. 低于 25% 且能与传统峰正式对齐的候选必须保留，继续计算面积、RT 和最终置信度；
6. 低于 25%、模型未命中、没有传统峰支持的候选可标记为 `WEAK_RELATIVE_CANDIDATE`，从正式 AI 峰/预警中排除，但写入审计表，便于追溯；
7. `NO_TRAD_SAMPLE` 场景不能按该规则直接删除，因为没有传统算法提供救援证据。

这套设计利用 25% 规则削减主要的低强度 `AI_ONLY_EXTRA`，同时保护模型高分峰和与传统算法一致的弱真峰。代价是不能在模型推理前减少 26.14% 的窗口；它优先保证召回和预警安全。

## 上线条件

正式启用前需要完整重跑 test1、test2 和 test3，并至少报告：候选减少率、模型推理时间、人工标签 TP/FP/FN、传统匹配峰保留率、AI_ONLY_EXTRA 减少率、红黄预警数量变化。当前证据支持把 25% 用作有救援条件的规则，不支持无条件硬删除。

## 极矮峰的报警控制

### 为什么不能只提高 SNR

当前 `scan_min_snr=10` 只作用于模型未命中的信号兜底候选，模型命中峰不经过该门槛。信号候选通过门控后，系统又会在最终边界和最终邻居集合上重算一次 SNR，因此最终 CSV 中仍可能出现 `snr < 10` 的信号峰。

test3 信号峰的 SNR 反事实结果如下：

| 最终 SNR 门槛 | 排除 AI_ONLY_EXTRA | 排除正式匹配信号峰 |
|---:|---:|---:|
| 10 | 1,280 / 8,028 | 233 / 3,332 |
| 15 | 3,051 / 8,028 | 475 / 3,332 |
| 20 | 3,995 / 8,028 | 648 / 3,332 |

此外，局部噪声估计接近零时，小峰也可能得到非常大的 SNR。test3 中存在超过 `1e13` 的 SNR 数值。因此 SNR 适合做最低信号质量检查，不适合独立判断峰在整个通道中是否小到可以忽略。

### 推荐的弱额外峰规则

在最终峰和传统峰完成对齐后，增加两个同通道相对量：

`relative_height = (I_apex - baseline) / (I_max - baseline)`

`relative_area = area_peak / max(area_all_ai_peaks_in_channel)`

推荐首轮工作点：

`relative_height < 0.10 AND relative_area < 0.10`

同时满足下列条件时，将峰归为 `IGNORED_WEAK_AI_EXTRA`：

1. 匹配状态为 `AI_ONLY_EXTRA`；
2. 来源为 `signal_rule`；
3. 没有传统峰正式匹配；
4. 没有同化合物另一 transition 在相近 RT 提供共洗脱支持；
5. 相对峰高和相对面积同时低于 10%。

处理方式：

- 保留峰、分数和排除原因到审计表；
- 多峰图中使用灰色虚线或灰色阴影；
- 不计入红色/黄色报警和人工复核数量；
- 正式匹配峰、模型峰和 `NO_TRAD_SAMPLE` 峰不受该规则直接抑制。

test3 反事实统计中，`相对峰高 < 10% 且相对面积 < 10%` 覆盖 1,793 个 `AI_ONLY_EXTRA`，其中 1,792 个为信号兜底峰。全体正式匹配峰中只有 1 个满足这两个弱峰条件；由于规则只作用于 `AI_ONLY_EXTRA`，正式匹配峰不会被抑制。

这套规则直接解决“多峰图中的极矮峰全部报红”问题，同时避免用单一 SNR 或 25% 强度硬门槛删除弱真峰。10% 是首轮测试工作点，后续应根据人工复核结果扫描 8%、10%、12% 和 15%。
