# 四模型双测试集网格对比评估报告（test1 + test2）

- 生成时间: 2026-09-03 23:33
- 模型: quanformer（baseline）/ quanformerv2（1000 样本微调）/ quanformerv3（traindatav1 全量重训）/ mrmpformer（新架构 MRMPFormer v3）
- 口径: score 阈值 {0.1,0.5,0.8,0.9,0.99} × 起止容差 {0.01,0.05,0.1,0.2,0.5} min；模型原始预测（未滤，score>0.01 生成后按阈值取子集）；ROI 平滑 0
- 命中判据: 预测起止 vs 人工起止偏差均 ≤ 容差（定量配对同容差）；QC 剔除 RT 双离子不一致通道

## 1. 执行摘要（结论先行）

- **mrmpformer 在 F1 上两集均居首**：test1 0.9/0.1 档 0.988、test2 0.809，且 precision 极高（test1 P=1.0、test2 P=0.977）——假阳性最少。
- **代价是 test2 上召回偏低**（0.9/0.1 R=0.69），特殊峰（多峰/宽峰/拖尾等低浓度复杂形）识别弱于 quanformerv3（5/44 vs 11/44）——高精低召的保守路线在困难样本上漏检更多。
- **数据对齐决定下限、架构决定上限**：老 quanformer baseline 两集 0.1 min 口径几乎全 miss（test1 F1≈0、test2 F1=0.017），边界约定不匹配；traindatav1 训练后同架构立即恢复到 0.74-0.98。
- quanformerv3（全量重训，激进检出）在困难集（test2）召回与特殊峰找回最强，但 FP 更多（test2 FP=45 vs mrmpformer 3）。

### 5.3 综合结论

- **mrmpformer = 高精度默认选择**：两集 FP 合计 3（test1 0 + test2 3），P 均 ≥0.98，边界偏差 ~0.01 min 级；适合对假阳性敏感的下游（如定量筛查）。
- **quanformerv3 = 高召回选项**：test2（困难低浓度集）召回与特殊峰找回领先（R 0.73、特殊 11/44 vs mrmpformer 5/44），但 FP 显著更多——适合『宁可复查不可漏』的全扫场景，或作为 mrmpformer 的召回兜底（两阶段/集成）。
- **数据是硬前提**：老 baseline 两集均失效（边界约定不匹配新 ROI 范式）；任何架构先决条件是 traindatav1 系数据训练。
- **0.99 超严阈值仅适用于 CE 校准模型**：mrmpformer（Focal）置信度软封顶 ~0.97，0.99 档无框；跨损失对比固定阈值需注意（详见原 test1 报告 §4 分析）。
